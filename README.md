# Leyes

> *Governing laws of cognitive alignment, taste, and ambiguity resolution for AI agents.*

`Leyes` turns human judgment, engineering taste, and tie-breaking rules into a modular 6-file Markdown matrix (`Morals.md`, `Ethics.md`, `Empathy.md`, `Love.md`, `Hate.md`, `Grey.md`) packaged as a portable AI agent skill.

## Quick Install (OpenCode, Hermes, Claude Code)
```bash
npx skills add blightedodyssey/leyes --skill=leyes
```

## The 6 Lenses
1. **`Morals.md`** — Non-negotiable personal North Star and hard red lines.
2. **`Ethics.md`** — External impact, accessibility, and system stewardship.
3. **`Empathy.md`** — Real-world hardware, network, and maintenance gravity.
4. **`Love.md`** — Aesthetic taste, deep-module craft, and learning-first ergonomics.
5. **`Hate.md`** — Anti-patterns, bloat, and lazy AI habits to actively reject.
6. **`Grey.md`** — Precedence rules, materiality threshold, and pause template when lenses collide.
